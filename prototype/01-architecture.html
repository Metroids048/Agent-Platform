双平台协作架构 — 运营平台 ⇄ 开发平台

运营平台管状态与治理，开发平台管实际运行；5 个协作环节把两边串起来。
⬇ 下载 SVG（拖入 Figma）

📌 设计要点

运营平台（本系统）
  • 管状态、审批、版本、两平台关联
  • 智能体是一等公民，资源只做引用
  • 智能体档案 = 业务侧全部记录
智能体开发平台
  • 模型 / 工具 / 知识库 / 工作流
  • 实际运行引擎 + 超时与轮次保护
  • 运行日志 = 实际运行数据
敖钦平台基座
  • 算力 / 模型推理路由 / 企业知识 API
  • Token 计量与 GPU 监控
  • 应用层经 platform-api.js 调用，不直接调度节点

敖钦基座 + 应用平台分层

用户门户敖钦对话入口 — 档位模型、会话 Skills
应用运行时组装 prompt + Skills → 敖钦推理

# 做什么 什么时候发生
① 同步创建智能体 用户点「确定」创建时
② 获取可用资源 进入编辑器，选模型/工具/知识库时
③ 同步配置 用户每次保存草稿时
④ 发起对话 沙箱试对话，或用户正式使用时
⑤ 回传运行数据 监控看板需要展示调用量、用量时
