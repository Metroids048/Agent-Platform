# AI 应用开发平台 — 项目情况汇总

> 一页总览，供领导评审、立项对齐、对外演示前阅读。  
> 详细报告见 [`docs/需求梳理/06-AI应用开发平台总结性需求报告.md`](../docs/需求梳理/06-AI应用开发平台总结性需求报告.md)，总索引见 [`docs/文档索引.md`](../docs/文档索引.md)。

**更新日期**：2026-06-08

---

## 1. 项目是什么

面向单位内部的 **AI 应用开发与中台运营平台**：不是单个聊天机器人，而是把「建应用 → 给用户用 → 收反馈 → 持续优化」做成闭环。

**核心设计**：以 **运营管理平台为中枢**，串联智能体开发、模型服务、知识中心、海能算力基座与权限治理。

---

## 2. 与海能平台的关系（已确认）

| 层级 | 谁负责 |
|------|--------|
| **海能平台** | 底层基座：算力、模型推理路由、企业知识库 API、计量、SSO |
| **我们平台** | 应用层：智能体编排、发布审核、运营看板、专家闭环、用户门户体验 |

智能体对话经我们「应用运行时」组装后，调用海能推理；用户看到**标准/增强/专业/旗舰**四档模型，不直接暴露底层供应商。

详见：[`docs/需求梳理/03-海能平台集成规范.md`](../docs/需求梳理/03-海能平台集成规范.md)

## 3. 六大子系统（讲稿六层）

| 子系统 | 一句话 | 材料成熟度 |
|--------|--------|------------|
| 运营管理平台 | 反馈、专家、看板、智能体上架治理 | ⭐⭐⭐ 讲稿+PRD+原型较全 |
| 智能体开发平台 | 画像、提示词、Skills、工具编排 | ⭐⭐⭐ 编辑器+Skills 可演示 |
| 海能用户门户 | 业务用户对话入口 | ⭐⭐ 极简页可演示，API 待接 |
| 资源服务中心 | GPU、部署、密钥 | ⭐ 讲稿+看板 mock，无完整页 |
| 模型服务平台 | 微调、数据集、评估 | ⭐ 仅讲稿 |
| 知识中心 | 个人/公共库、检索 | ⭐ 仅讲稿 |
| 系统管理 | 组织、角色、菜单 | ⭐⭐ 权限页有，全量系统管理无 |

## 6. 当前主要缺口（诚实标注）

1. **海能 API / SSO / 计量** — 文档有契约草案，未与对方签字确认。  
2. **模型服务、知识中心、智能编码** — 讲稿有、无独立产品页与 PRD 规划稿。  
3. **资源与成本管理** — 侧栏占位；仅有「资源看板」读数 mock。  
4. **用户反馈自动闭环** — 门户反馈 UI 有，未自动写入运营反馈列表（工程项）。  
5. **Figma 运营帧** — 38 帧中多数为 partial，5 处右键菜单、Peak Indicator 仍缺。

---

## 7. 建议演示顺序（现场）

1. 用精简讲稿讲 **L0 六层 + L1 运营闭环**（3 分钟）  
2. 打开 **运营管理** `index.html` → 智能体列表与看板  
3. 走 **创建 → 开发编辑 → 发布审核** 主链（`04`→`06`→`05`→`08`）  
4. 打开 **用户门户** `09-user-chat.html` 展示海能品牌与极简对话  
5. 打开 **用户反馈 + 专家工作台** 讲闭环（`11`→`12`）  
6. 打开 **四看板** `14-*` 讲数据汇聚（说明为 demo 数据）  
7. 收尾：**海能分工一页**（`03`）+ 下一步工作坊
