接口数据权限说明 ​

应用是外部系统调用平台开放接口的访问凭证。每个应用都对应一个具体的应用创建人，平台会基于该人员构建开放接口请求的用户登录态，具体的数据访问权限取决于该登录态。如果该创建人是租户管理员角色，则对应租户管理员的数据权限；如果是开发者角色，则对应开发者的数据权限。

1.2 参数说明 ​

header:

参数必选类型说明
traceId是string业务id
status是int数据状态，0：第一帧，1，中间帧，2，最后帧，3，结束帧

parameter:

参数必选类型说明
domain是string私有云：turing_general； 公有云：general； 公有云-大模型语音和识别-中文：generalzh
sessionParam是string会话参数，第一帧携带。后续携带无效

sessionParam:

参数数值说明
sidstring会话id，这个参数一定要传，方便以后检索日志
aueraw(pcm音频),speex, speex-wb， opus，opus-wb，opus-swb，g711_a,g711_u音频编码格式，未传入，当前只支持raw
rstjson,plain返回结果的格式，未传入默认json
bit8,16仅支持8位转16位， bit=“8”时会做位深转换，不传或者传入其他值不做转换
denoiseEnabletrue, false“true”时会作降噪处理。不传或其他值不做处理。该功能对于高质量音频可能有损耗
rseutf8,gbk识别结果的编码，未传入默认utf8
eos[1~2147483647]引擎参数，vad后断点值, 整数，毫秒，取值范围[1-2147483647]
dwawpgs引擎参数，是否获取中间结果
wbest[1~5]引擎参数，词级多候选
wbestonlypertrue,false引擎参数，是否只有人名多候选
nbest[1~5]引擎参数，句子多候选
rate16k,8k,6k采样率，如果传入的不是配置的采样率，则按照配置采样率识别
hotwordword1;word2;...采用;分割的热词，为utf-8编码
engine_paramKey1=value1;key2=value2引擎透传的参数，由;连接的引擎参数键值对
pgsModecomplex或者simple开启pgs时返回结果的格式
openwptrue或者false词语属性开关，返回结果中包含wp字段
domainjinrong|jisuanji|yiliao领域个性化功能，由|连接各领域名称
bos[1~2147483647]引擎参数，vad前端点值，整数，毫秒，取值范围[1-2147483647]
appIdstring使用个性化时appId的值
bizIdstring使用个性化时单个性化用户id
resIdListuid1,uid2使用个性化时有多个用户，第一个用户id以bizId传入，其余用户id以,拼接后传入
personal{ "Ids": [ { "bizId": "0001", "fIds": [ "111111", "222222" ] } ]}Json形式，用于指定使用bizId下具体某些资源功能，如果传入的bizId或者resIdList在personal中不存在，则使用全部资源；如果存在，则比较具体资源信息，在fIds中存在则使用，不存在则不使用
edAptText好的，我知道了，您平常吃菜，习惯吃的咸一点还是淡一点呢？文本字符串形式，utf8编码，需引擎支持ED_APT_TEXT文本资源

payload:

参数必选类型说明
samples是string语音base64
samplesInfo否string音频数据信息，扩展参数，保留
endFlag否boolean最后一次音频标志符,仅最后一次传输需要

header:

参数必选类型说明
traceId是string业务id
status是int数据状态，0：第一帧，1，中间帧，2，最后帧，3，结束帧

parameter:

参数必选类型说明
domain是string私有云：turing_general 公有云：general 公有云超拟人：general_cnr
sessionParam是string会话参数，第一帧携带。后续携带无效

sessionParam:

参数类型数值说明
sidstringstring会话id，建议客户端传此参数，方便以后检索
sample_ratestring8000/16000/24000采样率，xtts1.0和2.0默认为16000，xtts3.0和4.0默认为24000
frame_sizeint640/1280/1920当设置audio_coding参数为speex和speex-wb时，可通过此参数来固定每次编码块的大小（640的倍数，如：640、1280...）。
bit_depthint8,16仅支持8位转16位， bit=“8”时会做位深转换，不传或者传入其他值不做转换
audio_codingstringraw/speex/speexwb/lame/opus/opus-wb/opus-swb音频编码格式，默认raw
（公有云超拟人支持格式lame, speex, opus, opus-wb, opus-swb, speex-wb,opus-swb，默认为raw）
voice_namestringxiaoyan/catherine/...发音人名称（已废弃，建议使用native_voice_name代替）
native_voice_namestringxiaoyan/pe_John/...发音人名称（需和引擎的发音人名称保持一致，mtts暂时不支持此参数）
vidstringstring发音人的ID（名称和ID二选一传入，推荐使用id）
speedint-500~500语速，默认是0
volumedouble-20~20音量
nbestdouble[1~5]引擎参数，句子多候选
pitchdouble-500~500音高
read_all_marksdouble0~1是否读出所有的标点符号（只读中文标点）
read_numberdouble0~3读数字的方式
text_typedouble0~3输入文本格式
read_englishdouble0~2读取英文的方式
irf_pathStringstring.irf资源文件的路径（绝对路径或相对于启动目录的路径）
pydouble0~1是否输出音素信息
reset_paramdouble0~1是否重置参数，使用此参数可以在同一路会话中针对不同的文本设置不同的参数
emotiondouble0~13发音人使用的情感类别（需要配合多情感发音人使用）
emotion_scaledouble-20~20发音人的情感拉伸系数，默认为0
front_resultdouble0~1是否输出前端结果
front_result_onlydouble0~1是否只输出前端结果，无音频返回（需要配合front_result参数一起使用）

关于参数的取值详解：

read_number读数字的方式
0默认值，如果不确定按值读
1强制按数值读
2强制按数字串读
3自动判断，如果不确定按数字串读
text_type文本类型
0默认值，如果不确定按纯文本格式读取
1纯文本格式
2CSSML格式
3SSML格式
read_english读取英文的方式
0默认值，如果不确定按单词读
1强制按字母读
2自动判断，不确定则按字母读
