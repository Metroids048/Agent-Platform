1.2 参数说明 ​

接口请求字段由三个部分组成：header，parameter, payload。 字段解释如下：

header 部分 ​

参数名称类型必传参数要求参数说明
traceIdString是流程跟踪ID
bodyIdString是应用管理 -> 应用详情 -> 关联数据列表 -> 编码(复制)智能体编码
appIdString是应用管理 -> 应用详情 -> AppID(复制)APPID

parameter.chat 部分 ​

通常不需要传，后台会取默认值

参数名称类型
必传
参数要求
参数说明
domainstring否模型默认的名称模型名称，为空是默认配置模型。
temperaturefloat是取值为[0,1],默认为0.5核采样阈值。用于决定结果随机性，取值越高随机性越强即相同的问题得到的不同答案的可能性越高。简单来说，temperature 的参数值越小，模型就会返回越确定的一个结果。如果调高该参数值，大语言模型可能会返回更随机的结果，也就是说这可能会带来更多样化或更具创造性的产出。我们目前也在增加其他可能 token 的权重。在实际应用方面，对于质量保障（QA）等任务，我们可以设置更低的 temperature 值，以促使模型基于事实返回更真实和简洁的结果。 对于诗歌生成或其他创造性任务，你可以适当调高 temperature 参数值。
max_tokensInt是1024的整数倍，实际值取决于模型本身模型回答的tokens的最大长度
top_kInt是取值为[1，6],默认为4从k个候选中随机选择⼀个（⾮等概率）（与 temperature 一起称为核采样的技术），可以用来控制模型返回结果的真实性。如果你需要准确和事实的答案，就把参数值调低。如果你想要更多样化的答案，就把参数值调高一些。一般建议是改变其中一个参数就行，不用两个都调整。
top_pfloat否取值为(0.0, 1.0f]， 默认为0.0f动态设置候选列表的大小, 如0.15，表示取前15%概率的候选
adjustTokensboolean否默认为fasle输入tokens超过限制，自动截断历史信息文本进行tokens调整
contextEnabledboolean否默认为false,如需平台默认开启则需联系运维更改服务配置,优先级:不传值以服务配置为准,传入则以传入的值为准是否开启上下文

payload 部分 ​

参数名称类型
必传
参数要求
参数说明
sessionIdString否第一次会话可不传,会话响应会返回,进行多轮会话时必传会话id
messageobject是对话
functions否objectfunction call字段

payload.message.text 部分 ​

参数名称类型
必传
参数要求
参数说明
roleString是取值为[user,assistant,system]user表示是用户的问题，assistant表示AI的回复，system表示系统助手指令
content_typeString是目前支持：text；image（图片暂不支持）用户和AI的对话内容类型
contentString是参考模型实际的token上限用户和AI的对话内容

如果想获取结合上下文的回答，需要开发者每次将历史问答信息一起传给服务端。

2.2 参数说明 ​

接口为流式返回，此示例为最后一次返回结果，开发者需要将接口多次返回的结果进行拼接展示，接口返回字段分为两个部分，header，payload。字段解释如下：

header 部分 ​

字段名类型字段说明
codeInt错误码，0表示正常，非0表示出错；详细释义可在接口说明知识最后的错误码说明了解
messageString会话是否成功的描述信息
sidString会话的唯一id，用于讯飞技术人员查询服务端会话日志使用,出现调用错误时建议留存该字段
statusInt会话状态，取值为[0,1,2]；0代表首次结果；1代表中间结果；2代表最后一个结果
traceIdString流程跟踪ID

payload.choices 部分 ​

字段名类型字段说明
statusInt文本响应状态，取值为[0,1,2]
0代表首个文本结果
1代表中间文本结果
2代表最后一个文本结果
seqInt返回的数据序号，取值为[0,9999999]
textArrayAI的回答内容

payload.choices.text 部分 ​

字段名类型字段说明
contentStringAI的回答内容
content_typeString用户和AI的对话内容类型，目前支持：
text 文本
image（图片暂不支持）
roleString角色标识，固定为assistant，标识角色为AI

payload.context 部分

在最后一次结果返回

字段名类型字段说明
domainString使用的领域模型,如generalv3.5表示星火V3.5
chatIdString本轮会话id
codeInt聊天状态码，非0为异常回答（1.1.4.1021+版本后支持）
interruptBoolean是否中断会话, 部分错误码不允许继续会话。true：中断，不可再继续问答；false：可继续问答
promptString提示语

payload.usage 部分 ​

在最后一次结果返回

字段名类型字段说明
question_tokensInt保留字段，可忽略
prompt_tokensInt包含历史问题的总tokens大小
completion_tokensInt回答的tokens大小
total_tokensIntprompt_tokens和completion_tokens的和，也是本次交互计费的tokens大小
