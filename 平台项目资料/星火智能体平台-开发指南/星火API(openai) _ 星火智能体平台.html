1.2 参数说明 ​

接口请求字段由三个部分组成：header，parameter, payload。 字段解释如下：

header 部分 ​

参数名称类型必传参数要求参数说明
traceIdString是流程跟踪ID
bodyIdString是应用管理 -> 应用详情 -> 关联数据列表 -> 编码(复制)助手编码
appIdString是应用管理 -> 应用详情 -> AppID(复制)APPID
modeint否api调用传0请求类型

parameter 部分 ​

无论是智能体，还是任务链，用户在调用接口时都可以通过 parameter 传入自定义参数。

json
{
  "header": {
    "traceId": "xxx",
    "bodyId": "xxx",
    "appId": "xxx"
  },
  "parameter": {
    "loginId": "zhangsan"
  },
  "payload": {
  }
}

payload 部分 ​

参数名称类型必传参数要求参数说明
sessionIdString否第一次会话可不传,会话响应会返回,进行多轮会话时必传会话id
textobject是对话

payload.text 部分 ​

注：text下所有content累计内容 tokens需要控制在8192内

名称类型必传字段限制字段说明
roleString是取值为[user,assistant] user表示是用户的问题，assistant表示AI的回复
content_typeString是目前支持：text; form_inputtext：用户和AI的对话内容类型; form_input：对应会话页面的表单内容，接口传参仅需修改value字段
contentString是所有content的累计tokens需控制8192以内用户和AI的对话内容
formInputObject是任务型智能体表单内容根据具体任务型智能体确定传参内容

如果想获取结合上下文的回答，需要开发者每次将历史问答信息一起传给服务端。 注意：text里面的所有content内容加一起的tokens需要控制在8192以内，开发者如有较长对话需求，需要适当裁剪历史信息。

formInput.parameters部分： ​

名称说明
defaultValue默认值
desc描述
enableArc归一化处理
fullDesc完整描述
key键
name名称
optionStyle
props扩展字段
required是否需要
show是否展示
style展示的格式
type类型
value值

2.2 参数说明 ​

接口为流式返回，此示例为最后一次返回结果，开发者需要将接口多次返回的结果进行拼接展示，接口返回字段分为两个部分，header，payload。字段解释如下：

header 部分 ​

字段名类型字段说明
codeInt错误码，0表示正常，非0表示出错；详细释义可在接口说明知识最后的错误码说明了解
messageString会话是否成功的描述信息
sidString会话的唯一id，用于讯飞技术人员查询服务端会话日志使用,出现调用错误时建议留存该字段
statusInt会话状态，取值为[0,1,2]；0代表首次结果；1代表中间结果；2代表最后一个结果
traceIdString流程跟踪ID

payload.choices 部分 ​

字段名类型字段说明
statusInt文本响应状态，取值为[0,1,2]; 0代表首个文本结果；1代表中间文本结果；2代表最后一个文本结果
seqInt返回的数据序号，取值为[0,9999999]
textArrayAI的回答内容

payload.choices.text 部分 ​

字段名类型字段说明
roleString角色标识，固定为assistant，标识角色为AI
content_typeString用户和AI的对话内容类型，目前支持：
text 文本
image（图片暂不支持）
recommend 问题推荐
reference 引用归属
formInput 表单输入，当配了表单追问时触发
progress 技能执行过程
contentStringAI的回答内容

payload.choices.text.recommend 部分 ​

AI推荐的问题列表

字段名类型字段说明
recommendArrayAI推荐的问题列表

payload.choices.text.reference 部分 ​

引用归属

字段名类型字段说明
sourcesArray该轮会话引用的技能或知识库
- skillNameString技能名称
- iconString技能图标,格式如**TOSS_XX_TOSS**
- backgroundString技能背景,格式如**TOSS_XX_TOSS**
- docNameString文档名称,格式如**简历.docx**
- partsArray引用的文档片段
- - idStringID
- - titleString标题
- - contentString内容

payload.choices.text.formInput 部分 ​

表单输入，当配了表单追问时触发

字段名类型字段说明
parametersArray表单输入参数
- skillNameString技能名称
- keyString参数标识
- nameString参数名称
- descString参数描述
- valueString参数值
- defaultValueString默认值
- requiredBoolean是否必填
- styleString显示样式
- typeString参数类型

payload.choices.text.formOutput 部分 ​

表单输出，当配了任务链原样输出时触发

字段名类型字段说明
parametersArray表单输出参数
- skillNameString技能名称
- keyString参数标识
- nameString参数名称
- descString参数描述
- valueString参数值
- defaultValueString默认值
- requiredBoolean是否必填
- styleString显示样式
- typeString参数类型

payload.choices.text.progress 部分 ​

技能执行过程

字段名类型字段说明
skillString技能信息
- nameString技能名称
- skillInputString技能执行入参,格式如{'name': '张三', 'age': 30}
- skillOutputString技能执行出参,格式如{'name': '张三', 'age': 30}
- statusString执行状态0 表示开始执行，1 表示执行结束

payload.context 部分 ​

在最后一次结果返回

字段名类型字段说明
chatIdString本轮会话id
codeInt聊天状态码，非0为异常回答（1.1.4.1021+版本后支持）
interruptBoolean是否中断会话, 部分错误码不允许继续会话。
true：中断，不可再继续问答；
false：可继续问答
promptString提示语
docIdListList关联的知识点id列表

payload.usage 部分 ​

在最后一次结果返回

字段名类型字段说明
question_tokensInt保留字段，可忽略
prompt_tokensInt包含历史问题的总tokens大小
completion_tokensInt回答的tokens大小
total_tokensIntprompt_tokens和completion_tokens的和，也是本次交互计费的tokens大小
