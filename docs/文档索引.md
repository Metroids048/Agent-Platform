## 四、与代码仓库的关系（声明）

- **本文档体系描述的是「做什么、怎么串、缺什么」**，不替代 `prototype/` 内可点击原型。
- 原型用于验证交互与页面元素；真后端、SSO、海能 API 尚未落地。
- 修改产品边界时：先更新 `需求梳理/` 中文稿 → 再同步 `architecture/` 与 `decisions-log.md` ADR。
