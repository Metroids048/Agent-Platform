# AI应用开发平台 — 功能清单

> 生成日期：2026-06-23  
> 覆盖范围：运营管理平台（重点）、智能体开发平台、用户端Web门户  
> 原型基准：`prototype/` 下约35个HTML页面 + 对应JS模块

---

## 一、运营管理平台（智能体运营部分）

### 1.1 智能体卡片列表
| 二级功能 | 功能描述 |
|----------|----------|
| 智能体卡片展示 | 以卡片网格形式展示所有智能体，包含名称、类型、状态标签、可见范围、创建时间等信息 |
| 状态筛选 | 按草稿/审核中/已上架/已停用/已下架/已驳回筛选智能体列表 |
| 类型筛选 | 按问答型/任务型/流程型/多智能体类型过滤 |
| 权限筛选 | 按个人/组织/公开三种可见范围过滤 |
| 关键字搜索 | 按名称或描述搜索智能体 |
| KPI统计卡片 | 顶部展示智能体总数、已上架数、审核中数等运营关键指标 |
| 卡片更多菜单(⋯) | 根据智能体状态展示不同操作：发布、停用、启用、上架、下架、删除、权限设置 |
| 创建智能体 | 弹窗表单：填写名称、类型、可见范围，选择同步创建至开发平台 |
| 第三方智能体接入 | 弹窗表单：填写外部智能体信息、凭证、可见范围、审核规则 |

### 1.2 运营概览仪表盘
| 二级功能 | 功能描述 |
|----------|----------|
| 智能体总览统计 | 展示智能体总数、发布数、上架数、待审核数等核心运营数据 |
| 状态分布图表 | 按生命周期状态展示智能体分布 |
| 近期活动列表 | 展示最近创建、最近发布、最近有用户使用的智能体动态 |

### 1.3 审核工作台
| 二级功能 | 功能描述 |
|----------|----------|
| 待审核列表 | 展示所有提交发布申请的智能体审核队列 |
| 审核详情页 | 查看待审核智能体的基本信息、配置摘要、版本变更内容 |
| 审核通过 | 审批通过后智能体进入待上架状态，用户端可见 |
| 审核驳回 | 驳回申请并填写驳回原因，智能体回到草稿状态 |
| 审核进度追踪 | 展示审核流程当前节点与进度（如平台审核→专家审核） |
| 专家审核 | 高风险或特定类型智能体可分配给领域专家审核 |

### 1.4 智能体详情（05页）
| 二级功能 | 功能描述 |
|----------|----------|
| 基本信息Tab | 查看智能体名称、类型、状态、负责人、可见范围、创建时间等主数据 |
| 运行数据Tab | 查看智能体的调用量、Token消耗、响应时延、成功率等运行指标 |
| 版本与发布Tab | 查看候选版本信息、发布历史、当前上架版本 |
| 状态管理 | 发布、停用、启用、下架、重新发布等生命周期状态变更 |
| 跳转开发平台 | 从运营详情一键跳转到智能体开发编辑器进行配置修改 |
| 审核进度横幅 | 审核中/已驳回状态时展示审核进度或驳回原因 |

### 1.5 生命周期管理
| 二级功能 | 功能描述 |
|----------|----------|
| 发布流程 | 开发完成 → 提交发布申请 → 进入审核队列 → 审核通过待上架 → 上架用户可见 |
| 停用/启用 | 已上架智能体可临时停用（保留版本和范围），后续可重新启用 |
| 下架处理 | 将已上架智能体从用户可用入口移除，历史记录保留 |
| 重新发布 | 已下架/已驳回智能体支持修改后重新提交发布 |
| 删除 | 草稿/已驳回/已下架智能体支持彻底删除 |
| 状态流转记录 | 记录智能体每次状态变更的操作人和时间 |

## 二、运营管理平台（其他运营模块）

### 2.1 用户反馈管理
| 二级功能 | 功能描述 |
|----------|----------|
| 反馈列表 | 展示所有用户提交的反馈问题，含分类、优先级、处理状态 |
| 反馈详情 | 查看反馈原文、关联会话上下文、智能体信息 |
| 反馈分派 | 将反馈问题分配给指定团队或领域专家处理 |
| 反馈趋势图 | 按时间/类型/智能体统计反馈趋势 |
| 处理闭环 | 记录处理过程、结论和回流工单 |

### 2.2 专家工作台
| 二级功能 | 功能描述 |
|----------|----------|
| 任务池 | 展示所有待处理的专家任务列表 |
| 任务领取 | 专家从任务池领取任务进行处理 |
| 任务详情 | 查看任务上下文、原始对话、反馈意见 |
| 根因分析 | 判断问题归属：配置问题、知识缺失、模型能力、资源稳定性、权限设置 |
| 回流工单 | 根据归因生成工单回流到对应平台（开发/知识/模型/资源/系统管理） |
| 简化视图 | 提供精简操作界面快速处理 |

### 2.3 运营看板
| 二级功能 | 功能描述 |
|----------|----------|
| 业务看板 | 展示智能体使用量、用户活跃度、对话次数、满意度等业务指标 |
| 模型看板 | 展示模型调用量、Token消耗、响应时延、失败率等模型运行指标 |
| 资源看板 | 展示GPU/CPU资源使用率、推理服务状态、部署资源等 |
| 用户与智能体画像 | 展示用户使用行为和智能体表现的综合分析 |

### 2.4 权限与开发者管理
| 二级功能 | 功能描述 |
|----------|----------|
| 组织架构管理 | 管理单位、部门、团队等组织结构 |
| 角色管理 | 配置运营管理员、开发者、专家等角色及对应权限 |
| 开发者管理 | 开发者账号的增删改查与权限分配 |
| 权限条目管理 | 按角色配置菜单、功能、接口的访问权限 |

## 三、智能体开发平台

### 3.1 智能体开发列表
| 二级功能 | 功能描述 |
|----------|----------|
| 开发列表展示 | 展示所有可开发的智能体列表（从运营平台同步） |
| 搜索过滤 | 按名称/类型搜索智能体 |
| 进入编辑器 | 点击智能体进入三列编辑器进行配置 |

### 3.2 智能体编辑器（三列布局）
| 二级功能 | 功能描述 |
|----------|----------|
| 画像配置 | 配置智能体名称、描述、定位、角色人设等基本信息 |
| 能力配置 | 绑定提示词、模型档位、知识库、工具、MCP服务、工作流、Skills |
| 模型档位选择 | 选择DeepSeek-V4-Flash/Pro/R1-32B/R1-671B等模型档位 |
| 预览调试 | 实时预览和调试智能体对话效果 |
| 发布申请 | 保存配置并提交发布申请到运营平台审核 |

### 3.3 Skills管理
| 二级功能 | 功能描述 |
|----------|----------|
| Skills目录 | 展示所有可用的Skill资源（≥6个），含名称、描述、类型 |
| Skill创建 | 创建新的Skill资源 |
| Skill编辑 | 修改Skill的配置和内容 |
| Skill删除 | 删除不再使用的Skill |
| Skill绑定 | 将Skill绑定到具体智能体的能力配置中 |

### 3.4 资源选择器
| 二级功能 | 功能描述 |
|----------|----------|
| 知识库选择 | 从可用知识库列表中选择挂载 |
| 工具选择 | 从工具目录中选择绑定 |
| 能力组件选择 | 从组件中心选择MCP服务、工作流等 |

## 四、用户端Web门户

### 4.1 登录认证
| 二级功能 | 功能描述 |
|----------|----------|
| 企业邮箱登录 | 使用企业邮箱账号密码登录（Mock） |
| 记住密码 | 浏览器记住登录状态 |
| 忘记密码 | 密码找回流程 |
| 全站登录校验 | 未登录用户自动跳转登录页 |

### 4.2 对话工作台
| 二级功能 | 功能描述 |
|----------|----------|
| 智能体选择 | 侧栏按企业/组织/个人分组展示可用智能体，支持搜索、置顶、移除 |
| 智能体快捷列表 | 侧栏中区展示最近3-5个使用过的智能体 |
| 模型选择 | 顶栏下拉选择4档DeepSeek模型（全名显示） |
| 知识库切换 | 选择对话使用的知识库（企业/部门/文档等） |
| 多轮对话 | 支持多轮问答，消息气泡+Markdown渲染 |
| 消息操作 | 复制、重新生成、点赞、点踩、文件下载、引用查看 |
| 附件上传 | 通过+菜单上传图片/文件 |
| 引用笔记 | 通过+菜单引用个人笔记作为对话上下文 |
| 深度思考 | 开启深度思考模式进行复杂推理 |
| 历史对话管理 | 历史对话列表：保存笔记、重命名、删除（需确认）、保存个人智能体 |
| 用户反馈提交 | 对回答内容提交反馈（生成内容错误等） |

### 4.3 智能体广场
| 二级功能 | 功能描述 |
|----------|----------|
| Banner轮播 | 推荐智能体Banner轮播，支持左右箭头和hover暂停 |
| 分类Tab | 按推荐/全部/我的分组展示智能体 |
| 分类筛选 | 按智能体分类标签过滤 |
| 卡片展示 | 显示智能体名称、描述（限2行）、收藏状态 |
| 搜索 | 按名称/描述搜索智能体 |
| 收藏 | 收藏/取消收藏智能体 |
| 立即使用 | 点击后跳转对话页并自动选中该智能体 |

### 4.4 我的空间
| 二级功能 | 功能描述 |
|----------|----------|
| 个人资料 | 查看/编辑个人信息 |
| 个人笔记管理 | 创建、编辑、删除个人笔记；笔记含标题+摘要+全文 |
| 个人智能体管理 | 管理会话沉淀的草稿智能体和运营平台的个人/组织智能体 |
| 偏好设置 | 设置默认知识库、深度思考等用户偏好 |
| 修改密码 | 修改账号密码 |

### 4.5 消息中心
| 二级功能 | 功能描述 |
|----------|----------|
| 公告查看 | 查看平台公告通知 |
| 待办提醒 | 查看待处理的任务和审核提醒 |
| 反馈箱 | 查看已提交反馈的处理状态 |
| 意见反馈 | 提交平台使用意见 |
