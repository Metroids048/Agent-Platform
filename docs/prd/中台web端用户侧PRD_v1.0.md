一、产品概述
1.1 背景与定位
敖钦 AI 平台分为三大部分：
- 用户端：企业员工使用 AI 智能体的统一入口。包括对话工作台、智能体广场、个人空间、专家工作台和消息中心等功能。
- 运营平台：负责智能体的全生命周期管理——上架、审核、监控和工单流转。智能体需通过审核才能进入用户可见范围。
- 开发平台：负责智能体的技术配置、模型绑定和技能编排，为运营平台提供可发布的智能体。
用户端聚焦于日常使用场景：用户在对话工作台中选择智能体发起对话，在智能体广场中发现新的工具，在个人空间中管理自己的笔记和个人智能体，运营人员和专家在专家工作台中处理用户反馈。
产品定位：敖钦 AI 用户端是面向企业知识型员工的 AI 对话工作台 + 智能体发现 + 个人生产力空间。它让用户能够在一个界面中完成智能体搜索/选用、多轮对话、知识库检索、反馈提交、笔记沉淀和个人智能体管理。

智能体列表来自以下四个来源，按优先级聚合后分为三组展示（企业/组织/个人）：
1. 会话草稿：从历史对话生成的个人智能体草稿，仅创建者可见
2. 运营上架：运营平台审核通过的智能体
3. 演示数据集：原型阶段的内置演示数据
4. 预置企业兜底：系统预置的企业级智能体
分组规则：企业组对所有用户可见、组织组对同一组织的用户可见、个人组仅创建者可见。
